# PRAS - Flux v0.1

제주 태양광·ESS 구매·판매 요금 재무영향 시뮬레이터의 초기 GitHub Pages 버전입니다.

## 실행
1. 폴더 전체를 GitHub repository에 업로드합니다.
2. Settings → Pages에서 브랜치의 root를 배포 대상으로 지정합니다.
3. 로컬에서는 `index.html`을 직접 열어도 동작합니다.

## v0.1 데이터
- 부하: `260811_Flux 요금제 시뮬레이션.xlsx`에 정리된 2025년 제주 TOU 약 1,200호의 24시간 평균 사용량.
- 태양광 shape: `태양광 발전량_2025.xlsx` 89호의 실제 태양광 발전량에서 산출된 시간대별 발전 비중.
- 태양광 규모 기본값: 기존 Flux 프로토타입의 10.8kWh/대표일. 버튼으로 89호 실측 평균 4.70kWh/일 적용 가능.
- 구매단가: 기존 Flux 파일의 기준/변경 단가.
- 판매단가: 변경 전 자료가 아직 별도 제공되지 않아 기준·신규 모두 Flux 역송단가를 동일 적용한 임시값.

## 계산 로직
- 부하와 PV를 차감한 순부하를 계산합니다.
- ESS 보유 고객은 24시간 동적계획법(DP)으로 전력량요금 순지출을 최소화합니다.
- ESS 정격용량, SOC 하한/상한, 초기·종말 SOC, 충방전 출력, 왕복효율, 계통충전 허용, ESS 역송 허용을 제약으로 반영합니다.
- 기준안과 신규안을 각각 최적화하여 요금 신호에 따른 충방전 행동변화를 반영합니다.
- 한전 관점 재무영향은 `전력판매수익 - 고객전력 매입지급액`으로 계산합니다.
- 총 변화는 구매단가 효과, 판매단가 효과, 충방전 행동효과로 분해됩니다.

## 범위
기본요금, 연료비조정액, 기후환경요금, 부가세, 전력산업기반기금은 제외하고 전력량요금만 계산합니다.

## v0.1 한계 및 다음 확장
- 현재 2025년 대표 24시간 평균을 365일 연간화합니다.
- 업로드된 2021~2024 TOU 원자료는 v0.2에서 연도별/월별 프로파일로 직접 연결하는 것이 적절합니다.
- 2025년 태양광 89호와 TOU 고객번호가 매칭되므로, 후속 버전에서는 63호 완전자료 고객을 중심으로 실제 고객별 8,760시간 back-test 탭을 추가할 수 있습니다.
- 변경 전/후 판매단가가 확정되면 UI의 24시간 단가표만 교체하면 됩니다.
